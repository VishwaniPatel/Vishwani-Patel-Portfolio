# Vishwani Patel Portfolio

React + Vite + Tailwind CSS + Framer Motion portfolio based on the supplied resume.

## Run

```bash
npm install
npm run dev
```

Open the local URL shown by Vite.

## Production build

```bash
npm run build
npm run preview
```

## Resume

Place the supplied resume PDF at:

`public/Vishwani_Patel_Frontend_Developer.pdf`

The Hero "Download Resume" button expects that path.
